# officialunofficial/homebrew-tap

A [Homebrew](https://brew.sh) tap for tools published by `officialunofficial`.

## Install

```sh
brew tap officialunofficial/tap
brew install <formula>
```

## Available formulae

| Formula | Description | Source |
|---|---|---|
| `mkit` | Content-addressed VCS toolkit (Zig). | https://github.com/officialunofficial/mkit |

(More formulae will be added as projects ship.)
